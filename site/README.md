# Book site (Docusaurus)

This is an isolated Node project publishing the book to GitHub Pages. It is not the source of
the book's prose: that lives in `../chapters/`.

`site/docs/` is generated and gitignored - it is regenerated by `scripts/sync-docs.mjs` from
`../chapters/chapter-N/chapter-N-text.md` on every `start`/`build`. Never hand-edit anything
under `site/docs/`; edit `../chapters/` instead and re-run the sync.

## Commands

```bash
npm ci
npm run sync    # regenerate site/docs/ from ../chapters/ only, no dev server
npm start        # sync, then local dev server
npm run build    # sync, then static production build into site/build/
```

## How the sync works

Each chapter's first `# ` heading becomes its page title. Chapters 1-18 are placed into one
of 8 numbered Part folders (matching `CLAUDE.md` section 1's table) so Docusaurus's
autogenerated sidebar reproduces the book's Part groupings automatically; chapters 0 and 19
and the two appendices are placed at the top level instead. Missing chapter files are skipped
with a warning on stderr, exactly like `build-book.sh` does for the pandoc build.

## Deployment

`.github/workflows/deploy-site.yml` runs the sync and build, then publishes `site/build/` to
GitHub Pages on every push to `main`. Locally, `npm run build` followed by `npm run serve`
lets you preview the production build before pushing.
